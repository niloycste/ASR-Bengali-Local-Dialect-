# AncholVox — A Silver-Standard Diagnostic Benchmark for Regional Bengali ASR

**AncholVox** is a silver-standard speech dataset for **Automatic Speech Recognition (ASR)** across **15 Bangladeshi regional labels**, with Bengali–English code-switching detected in the automatic transcripts. The regional and switching labels are diagnostic metadata rather than manual acoustic verification.

| | |
|---|---|
| **Clips** | 41,499 transcribed audio clips |
| **Duration** | ~131.2 hours |
| **Historical splits** | train 34,605 · validation 2,806 · test 4,088 |
| **Dialects** | 15 Bangladeshi regional dialects |
| **Languages** | Bengali (`bn`) + English (`en`) code-switching |
| **Audio** | 16 kHz mono, 5–15 s per clip |
| **Transcript-detected code-switched clips** | 2,361 (~5.7%) |
| **Access** | Audio gated; redistribution review pending |
| **Compilation/code license** | CC BY-NC 4.0 (does not grant third-party audio rights) |

These 41,499 clips are the retained silver-standard subset of 52,020 segmented clips (48,772 after language filtering; 48,484 entered the confidence cascade). This release contains **real recordings only** — audio augmentation used for training the paper's models is a training-time choice and is **not** included; apply it yourself if needed.

> ⚠️ **Labels are silver-standard** — transcripts were generated by Whisper large-v3 and textually filtered by an LLM judge, **not** verified against audio by human transcribers at corpus scale. WER and CER measure agreement with these noisy references, not definitive transcription accuracy. A limited 100-clip, two-annotator study characterizes label uncertainty but does not establish model rankings.

> **Release gate:** Public accessibility of the source videos is not permission
> to redistribute their audio. Institutional/ethics review, a redistribution
> determination, and per-source allow/remove decisions are pending. Hosted
> audio must remain unavailable until all three are cleared; where permission
> is absent, release is limited to permissible metadata, source pointers, and
> processing code. See `ETHICS_AND_DATA_GOVERNANCE.md`.

> **Historical split warning:** The paper's archived test split is not
> source-disjoint from the retained remainder (69/101 inferred test sources
> cross the boundary; 326 exact-audio duplicate groups also cross it). Existing
> fine-tuned scores are diagnostic, not leakage-free generalization estimates.
> A repaired split is frozen for future retraining, but no repaired-split model
> result is currently reported.

## How to use

```python
from datasets import load_dataset, Audio

ds = load_dataset("niloycste68/Bangali_local_dialect_ASR_HF_Dataset")

# decode audio to 16 kHz waveforms on access
ds = ds.cast_column("audio", Audio(sampling_rate=16000))

example = ds["train"][0]
print(example["sentence"])           # transcript (Bengali, may contain English)
print(example["dialect"])            # e.g. "Sylhet"
print(example["is_code_switched"])   # True / False
waveform = example["audio"]["array"] # numpy float array @ 16 kHz
```

Filter to only code-switched clips:

```python
cs = ds["train"].filter(lambda x: x["is_code_switched"])
```

## How it was built

Audio was collected from selected public social-media sources using **dialect-name** search queries across code-switch-rich genres (vlog, technology/phone review, campus/career, street interview, gaming). Long recordings were segmented into 5–15 s clips with WebRTC voice-activity detection, transcribed with **Whisper large-v3**, and labelled for code-switching from Unicode script ranges (Bengali vs. Latin). High-confidence transcripts were auto-accepted; borderline transcripts received text-only filtering by **Qwen2.5**. That judge cannot verify acoustic correctness, and the detected 5.7% CS rate is a property of the automatic transcripts rather than a population estimate.

## Intended use & limitations

- **Intended use:** diagnostic research on silver-labelled dialectal and code-switched Bengali ASR, subject to the release gate above.
- **Limitations:** noisy silver references; non-standardized dialect orthography; imbalanced online-source coverage; no external-corpus evaluation; no consented demographic labels; no population-wide dialect or fairness claims; historical split leakage; and possible Whisper-family reference bias. Clips from related source videos are dependent, and source IDs do not prove speaker independence.
- **Inference discrepancy:** using archived construction-time Whisper large-v3 transcripts as references, paired evaluation-time outputs differ at 0.9271 WER; the same evaluation outputs score 0.9298 WER against the stored silver references. Current code paths use different backends and decoding settings, but missing historical revisions/settings prevent a unique retrospective explanation. Full definitions and artifact hashes are in `REFERENCE_PIPELINE_PROVENANCE.md` in the code repository.
- **Ethics and rights:** public availability does not authorize redistribution. No speaker identities, demographics, or contact information are intentionally released. Non-commercial terms do not replace source-specific permission.
