## ✨ Overview

**BanglaMix** is a challenging open benchmark for **Bangladeshi regional dialect Automatic Speech Recognition** under realistic **Bengali–English code-switching** conditions.

Unlike existing Bengali ASR datasets that focus on either standard Bengali, dialects, or limited code-switching, BanglaMix targets the intersection that appears naturally in young Bangladeshi online speech:

> “chatgaiya bhashay phone unboxing kortachi, honestly speaking camera performance onek bhalo”

The benchmark covers **15 regional dialects** and **41,499 transcribed clips** (about **131.2 hours**) of real-world speech, curated from 51,857 segmented clips through silver-standard validation.

> ⚠️ **Important label note**  
> BanglaMix uses **silver-standard labels** generated by Whisper large-v3 and refined through an LLM-based quality pipeline. It is therefore positioned as a **challenging open benchmark**, not a solved transcription dataset. A 200-clip human-validation study is included to quantify silver-label quality.

## 🔍 Why BanglaMix?

Existing Bengali ASR resources usually cover **either dialectal speech or code-switching**, but not both together.

| Dataset | Dialectal Speech | Code-Switching | Hours |
|---|:---:|:---:|---:|
| OpenSLR-37 | ❌ | ❌ | 100 |
| MUCS 2021 | ❌ | ✅ Standard Bengali only | 16 |
| Ben-10 (2025) | ✅ 10 dialects | ❌ | 78 |
| **BanglaMix** | ✅ **15 dialects** | ✅ **Bengali + English** | **~131** |

BanglaMix addresses this gap by focusing on realistic speech from online content where speakers naturally mix:

- regional Bangladeshi dialects,
- standard Bengali forms,
- English words and phrases,
- informal spoken-language spelling variation,
- noisy real-world audio.

## 🏆 Benchmark Results

All models were evaluated on a **held-out test set of 4,088 clips**. The split is source-isolated and dialect-stratified.

**Lower WER/CER/WER-CS is better. Higher CS-F1 is better.**

| Model | WER ↓ | CER ↓ | WER-CS ↓ | CS-F1 ↑ |
|---|---:|---:|---:|---:|
| Whisper-small zero-shot | 1.07 | 1.02 | 1.02 | 0.00 |
| Whisper large-v3 zero-shot | 0.91 | 0.76 | 0.80 | 0.14 |
| MMS-1B zero-shot | 0.99 | 0.57 | 0.94 | 0.04 |
| wav2vec2-XLS-R-BN zero-shot | 0.96 | 0.62 | 0.94 | 0.04 |
| wav2vec2 fine-tuned CTC | 0.86 | 0.49 | 0.88 | 0.14 |
| Whisper FT BN-only | 0.80 | 0.49 | 0.82 | 0.01 |
| Whisper FT CS-only | 0.88 | 0.55 | 0.81 | **0.28** |
| **Whisper FT ALL proposed** | **0.80** | **0.49** | **0.82** | **0.19** |

### 📊 Main Findings

- Fine-tuning Whisper-small on BanglaMix reduces WER from **1.07 → 0.80**, a **25% relative improvement**.
- The proposed model significantly beats:
  - every zero-shot baseline,
  - Whisper large-v3 zero-shot,
  - the fine-tuned wav2vec2 CTC model.
- Whisper FT ALL is statistically tied with the BN-only ablation on overall WER (_p_ = 0.54).
- The advantage of training on all data appears most clearly in **code-switch handling**.
- The CS-only ablation achieves the strongest code-switch preservation signal, with **CS-F1 = 0.28**.
- An independent LLM-ensemble evaluation also ranks the proposed system best overall.

> 💡 **Why are WER values high?**  
> This task is intentionally difficult: 15 low-resource dialects, real-world audio, code-switching, spelling variation, and silver-standard labels. Since dialectal Bengali has no standardized spelling, **CER is often more informative than WER** for this benchmark.

## ⚙️ Installation

### 1. Create the environment

```bash
conda create -n ASR python=3.12
conda activate ASR
```

### 2. Install PyTorch

Replace `cu121` with the CUDA version that matches your system.

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 3. Install project dependencies

```bash
pip install -r requirements.txt
```

### 4. Install system and optional dependencies

#### ffmpeg

Required for audio loading and Whisper.

```bash
# Windows
winget install ffmpeg

# Linux
sudo apt install ffmpeg
```

#### Ollama

Required for the LLM transcript judge and LLM-ensemble evaluation.

```bash
ollama pull qwen2.5
ollama pull mistral:7b
ollama pull llama3.1:8b
ollama pull gemma3:12b
```

#### KenLM + pyctcdecode

Only required for optional CTC language-model shallow fusion.

```bash
pip install https://github.com/kpu/kenlm/archive/master.zip pyctcdecode
```

## 🔁 Reproduce Step by Step

A GPU is strongly recommended for transcription, fine-tuning, and baseline evaluation.

> 📦 Dataset-only usage  
> If you only want to use the dataset, download it from [Hugging Face](https://huggingface.co/datasets/niloycste68/Bangali_local_dialect_ASR_HF_Dataset) and skip Phase 1.

---

### Phase 1 — Build the Dataset

```bash
cd dataset_pipeline

python 01_download_audio.py
python 01b_download_extra_urls.py
python convert_webm.py

python 02_segment_audio.py
python 03_auto_transcribe.py

python 04a_retag_borrowed_english.py
python 04b_auto_annotate.py
python 04c_llm_transcript_judge.py

python 05_build_dataset.py
```

### Annotation Pipeline

| Condition | Action |
|---|---|
| `no_speech_prob < 0.30` | Auto-accept transcript |
| `0.30 ≤ no_speech_prob < 0.60` | Qwen2.5 LLM judge reviews transcript |
| `no_speech_prob ≥ 0.60` | Reject clip |

The LLM judge evaluates:

- Bengali validity,
- code-switch naturalness,
- dialect authenticity,
- hallucination risk,
- transcript usability.

> The 3-model LLM ensemble is used only for evaluation, not dataset construction.

### Final Splits

The training pool includes augmentation. Dev and test sets are real and unaugmented.

| Split | Clips | Hours | CS Clips | CS % |
|---|---:|---:|---:|---:|
| Train | 60,936 | 188.4 | 4,485 | 7.4 |
| Dev | 2,806 | 9.1 | 166 | 5.9 |
| Test | 4,088 | 13.2 | 176 | 4.3 |
| **Total** | **67,830** | **210.8** | **4,827** | **7.1** |

---

### Phase 2 — Fine-Tune Models

```bash
cd ../fine_tuning

python 01_prepare_hf_dataset.py
python 02_finetune_whisper.py
python 03_finetune_wav2vec2.py
```

| Output Path | Training Data | Role |
|---|---|---|
| `models/ft_whisper_all/` | Bengali + code-switched clips | Proposed system |
| `models/ft_whisper_bn_only/` | Dialect-only Bengali clips | Ablation A |
| `models/ft_whisper_cs_only/` | Code-switched clips only | Ablation B |
| `models/ft_wav2vec2_all/` | All clips | CTC comparison |

### Training Configuration

| Model | Size | LR | Epochs | Warm-up | Selection |
|---|---:|---:|---:|---:|---|
| Whisper-small | 244M | `1e-5` | 3 | 500 steps | Best dev WER |
| wav2vec2-XLS-R | 300M | `1e-4` | 3 | — | Best dev WER |

Mixed precision training uses `bf16` or `fp16` depending on hardware support.

## 📏 Metrics

| Metric | Meaning |
|---|---|
| **WER** | Word Error Rate |
| **CER** | Character Error Rate; primary metric because it is more robust to spelling variation |
| **WER-BN** | WER restricted to Bengali-script reference words |
| **WER-EN** | WER restricted to English-script reference words |
| **MIX-ER** | Token is correct only if both word and script match |
| **WER-CS** | WER on code-switched clips only |
| **CS-F1** | F1 for detecting whether a hypothesis contains code-switching |
| **EN-Survival** | Fraction of English reference words preserved on code-switched clips |
| **Bootstrap CI** | Paired bootstrap confidence interval |
| **p-value** | Paired bootstrap significance test |
| **Cohen’s d** | Effect size based on corpus WER resampling |

## 🧠 Key Design Decisions

### 1. Dialect-name queries instead of region-name queries

Region-name queries such as “Chittagong vlog” often return speakers from a region using standard Bengali for a general audience. Dialect-name queries are more likely to surface creators who deliberately speak in the dialect.

### 2. Content genres that naturally trigger code-switching

Search queries target content where English mixing is common and spontaneous:

- street interviews,
- reaction videos,
- technology and phone reviews,
- campus and career discussions,
- gaming and livestreams,
- personal vlogs.

### 3. Silver-standard transcription

Whisper large-v3 is used as a best-effort multilingual transcriber. Script-based code-switch detection is reliable because Bengali and Latin characters occupy separate Unicode ranges.

A human-validation subset is included to estimate label quality and benchmark reliability.

> Caveat: Since labels are generated by Whisper large-v3, the benchmark may slightly favor Whisper-family systems.

### 4. Whisper as the proposed model

Whisper has a multilingual subword vocabulary that can represent both Bengali and Latin-script tokens in a single decoding pass. This makes it better suited to mixed-script code-switching than monolingual CTC systems.

## ✅ Recommended Use

BanglaMix can be used for:

- dialectal Bengali ASR,
- Bengali–English code-switching research,
- robust speech recognition under noisy real-world conditions,
- cross-dialect ASR evaluation,
- mixed-script recognition metrics,
- silver-label benchmarking studies.

---

## ⚠️ Limitations

- Labels are silver-standard, not fully human-transcribed.
- Dialect spelling is not standardized.
- WER may over-penalize valid spelling variation.
- Online-source distribution is not demographically balanced.
- Whisper-generated labels may introduce model-family bias.
- Code-switching frequency varies by source, genre, and dialect.
